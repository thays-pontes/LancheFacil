# Lanche Fácil - App de Registro de Pedidos

Exercício Avaliativo.

## Funcionalidades

- Tela inicial com logomarca e botão para iniciar o pedido.
- Formulário para o cliente inserir nome e escolher o lanche.
- Resumo do pedido com nome do cliente e lanche escolhido.

## Como Usar

1. **Tela de Boas-Vindas**: Clique no botão para começar o pedido.
2. **Formulário de Pedido**: Insira seu nome e escolha o lanche.
3. **Resumo do Pedido**: Visualize seu nome e o lanche selecionado.

## Tecnologias

- **Android Studio**
- **Java**
- **XML** para o layout.
